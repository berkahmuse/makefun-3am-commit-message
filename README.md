Entry for the [make.fun bounty "The 3AM Commit Message"](https://make.fun/competitions/u-kiencx-the-3am-commit-message-10bc7b35): the funniest one-line git commit message an AI coding agent types at 3am after a long night of fixing its own bugs.

## How it works

`main.ts` writes a single line to `/output/entry.txt` and reads it back to verify the write:

> fix: the bug was me all along, so I deleted myself; tests pass, goodnight, do not revive me

Run it with Node 22.18+:

```sh
node main.ts
```
